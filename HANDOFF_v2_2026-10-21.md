## 4. APIs Disponibles

### Auth
```
POST /api/auth/login        → { username, password } → { token, user }
GET  /api/auth/me           → Bearer token → { user, permissions }
POST /api/auth/logout       → Bearer token → { success }
GET  /api/auth/roles        → Lista de roles disponibles
```

### Admin (requiere canManageRoles o canCreatePolicies)
```
GET  /api/admin/users       → Lista usuarios
POST /api/admin/users       → Crear/actualizar usuario
GET  /api/admin/policies    → Lista políticas DAM
POST /api/admin/policies    → Crear política
PUT  /api/admin/policies/:id → Actualizar política
DELETE /api/admin/policies/:id → Desactivar política
GET  /api/admin/squads      → Lista squads
POST /api/admin/squads      → Crear squad
GET  /api/admin/api-keys    → Lista API keys (truncadas)
POST /api/admin/api-keys    → Crear API key
POST /api/admin/generate-code → Generar código de acceso
GET  /api/admin/view-config → Config de vistas por rol
PUT  /api/admin/view-config → Actualizar config de vistas
```

### Aprobaciones
```
GET  /api/notifications/pending     → Assets pendientes (requiere canApprove)
POST /api/assets/:assetId/approve   → Aprobar asset (requiere canApprove)
POST /api/assets/:assetId/reject    → Rechazar asset (requiere canApprove)
```

### API Pública (con X-API-Key header)
```
GET  /api/public/assets                    → Assets aprobados/publicados
GET  /api/public/assets/:assetId/status    → Estado de un asset específico
```

### Conexiones Externas
```
GET  /api/connections                    → Lista conexiones (requiere canConnectExternalDB)
POST /api/connections                    → Guardar nueva conexión
POST /api/connections/:connId/provision  → Provisionar estructura DAM
```

### Flow Studio
```
GET  /api/flow-studio/templates  → Lista de plantillas disponibles
GET  /api/flow-studio/preview    → HTML del diagrama (query: ?template=KEY)
POST /api/flow-studio/generate   → Generar HTML con titulo/template personalizado
```
